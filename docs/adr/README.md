# Architecture Decision Records

This directory is a collection of very simple and informal [architecture decision records](https://adr.github.io/) (ADRs).
I just want to remember why I chose X over Y.

ADRs use 4-digit sequential filenames (`0001-slug.md`, `0002-slug.md`, ...).
Detailed format and guidance on when an ADR is worth writing live in the
`grill-with-docs` skill (`.claude/skills/grill-with-docs/ADR-FORMAT.md`).
